## Hypothesis and end state

Test V35's derivative-supervised independent whole-MLP replacement on
pretrained decoder checkpoints whose metadata was seen but whose weight or
execution exposure is not recorded in the bound retained corpus. This is a
development transfer study. It is not wholly unseen checkpoint confirmation
or training-ancestry independence. Prior V36/R1/R2 terminal dispositions and
frozen bytes remain intact. Preserve every miss; no scientific retuning.

The new exposure audit is bound before intake/selection. Eligibility requires
its literal `METADATA_ONLY_IN_RETAINED_CUSTODY` class. Unknown, previously
downloaded and execution-recorded identities are excluded. Every retained
weight hash, including unattributed candidate files, is excluded. Identical
public copies cannot become fresh by renaming. Unretained/remote/other-project
history and aliases remain limitations; no universal never-used assertion.

## Fixed selection and acquisition

After this source freeze, derive up to 200 candidates per architecture from
the retained V27 `v27-hub-screen.json` query projections. Keep exact model_type
OPT, GPT-2 or Llama, public ungated status and audited metadata-only identities;
retain existing random/dummy/instruction/chat/fine-tuned/adapter/quantized name
exclusions. Deduplicate case-insensitive identities and order by recorded
downloads descending, then identity ascending. This makes no inference from
model outputs. Use each recorded 40-hex revision; a changed or inaccessible
revision is a literal stop, not an implicit fallback or moving-head retry.

For each family nominate the first passing candidate. Keep V36R1's pinned
card license set, from-scratch provenance, no declared parent model,
250M parameter cap, width 8-1024, depth at least four, vocabulary at most
65,536, expected activation, safe complete weights/tokenizer, no custom code,
no quantization or pickle, per-checkpoint 1.1 GiB cap. Cards are publisher
claims, not independently verified rights or training quality. The Hub
[model-card specification](https://huggingface.co/docs/hub/model-cards) explains
license and parent metadata. Missing provenance remains an exclusion.
Bounded public unauthenticated metadata/static-asset downloads require the
explicit CLI opt-in. No inference endpoint, paid execution or remote worker.

Seal every nomination together before any weight download. If no family
qualifies, stop. If one or two qualify, run only those predeclared finite
family studies and report `PARTIAL_DEVELOPMENT_COHORT_READY`; do not discard
runnable evidence or present it as a nine-case cohort. Three families are
required for the overall three-family claim. No model asset enters the repo.

## Scientific obligations, unchanged numerics

Each eligible family is a separate study with three seeds (36101, 36102,
36103), the unchanged JVP treatment and endpoint comparator, two sequential
independently initialized whole-MLP replacements, visible-only target selection
and task-critical removal gates, disjoint adaptation, held-out challenges
generated after its candidate freeze, and predictions sealed before oracle
effects. Each family freezes all seeds/arms before revealing its challenges.
No family result changes the source, selection or another family's fitting.

The V36 core, fixture generation, capture semantics, optimizer, 1,024 updates,
gradient cap, final-token fitting, intervention/rescue definitions, strata,
controls, row disjointness and every numeric gate are frozen unchanged.
Details: [V36 protocol](replacement-loss-v36-pretrained-transfer.md).
Each selected site's visible removal needs logit nRMSE >= .10 and top-1
change >= .20. A family that fails target qualification stops before fitting
and receives `NO_QUALIFIED_TARGET`; other family studies retain their own
obligations. Treatment passes require all stages/strata and controls in all
three seeds. Overall nine-case PASS requires all three families and all nine
complete JVP cases; missing/unknown outcomes do not count as passes.

Frozen endpoints are the same output nRMSE <= .10, top-1 agreement >= .95,
mean NLL increase <= .03, resolved causal effects >= .90, median relative
effect error <= .20, p90 <= .50, median cosine >= .90, activation <= .15,
rescue <= .10, prediction of rescue <= .10, and negative-control gap >= .10.
Endpoint comparison is descriptive, with no post-hoc superiority promotion.
Model/corpus/intervention sensitivity are variance sources. Three seeds are
fixture/replacement repeats within a checkpoint, not independent checkpoints.

Exact primary and replica use distinct isolated external runtime prefixes
with Python 3.12.13 and the same 34-package V36 lock; shared physical host and
system libraries are disclosed. Replica reconstructs its candidates before
entropy reveal. Separate persisted-array closeout rechecks seals, all arrays,
gates, controls, artifacts and reconciliation. No independent authority is
asserted by these processes. If a family stops pre-fit, reproduce that literal
stop and report zero assessed cases.
